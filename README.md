# Grocery Store Management System

## Description
The Grocery Store Management System is a web application that allows users to manage grocery items, including adding, updating, deleting, and viewing products. It provides an intuitive interface for both customers and store managers to interact with the grocery inventory.

## Features
- User authentication (login and registration)
- View a list of grocery items
- Add new grocery items
- Update existing grocery item details
- Delete grocery items from the inventory
- Search functionality for quick access to products

## Technologies Used
- **Backend**: Spring Boot
- **Database**: HSQL , PostGreSQL (or any other database as per implementation)
